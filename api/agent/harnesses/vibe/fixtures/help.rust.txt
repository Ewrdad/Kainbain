Run the Mistral Vibe interactive CLI

Usage: vibe [OPTIONS] [INITIAL_PROMPT] [COMMAND]

Commands:
  mcp   Manage MCP server configuration without starting a session
  help  Print this message or the help of the given subcommand(s)

Arguments:
  [INITIAL_PROMPT]  Initial prompt for the interactive session, or the prompt in headless mode

Options:
  -v, --version
          Show version and exit
      --workdir <CWD>
          Change to this directory before running [env: VIBE_CWD=]
  -c, --continue
          Continue from the most recent saved session
      --resume [<RESUME>]
          Resume a session. Without SESSION_ID, shows an interactive picker
      --setup
          Setup API key and exit
  -p, --prompt [<PROMPT>]
          Run in headless (programmatic) mode: send prompt, output response, exit
      --output <OUTPUT>
          Output format for headless mode [default: text] [possible values: text, json, streaming]
      --max-turns <MAX_TURNS>
          Maximum number of assistant turns (headless mode only)
      --max-price <MAX_PRICE>
          Maximum cost in dollars (headless mode only)
      --max-tokens <MAX_TOKENS>
          Maximum total prompt + completion tokens (headless mode only)
      --time-limit <SECONDS>
          Interrupt the run once SECONDS have passed since start, write the export and exit 3. SIGTERM stops the run the same way
      --prompt-file <PATH>
          Run in programmatic mode with the prompt read from PATH, instead of -p TEXT or stdin
      --output-dir <DIR>
          On every exit, write export.json (Vibe version, effective config, token usage, cost, stop reason, outcome) and a copy of the session journal (session/) to DIR
      --agent <NAME>
          Agent to use (builtin: ask, accept-edits, smart-approve, auto-approve, or custom from ~/.vibe/agents/NAME.toml). Defaults to the 'default_agent' config setting
      --auto-approve
          Approves all tool calls without prompting for the selected agent [alias: --yolo]
      --smart-approve
          Classify each tool call and auto-run the safe ones, prompting only for risky ones
      --enabled-tools <ENABLED_TOOLS>
          Enable specific tools (headless: disables all others). Repeat the flag
      --disabled-tools <DISABLED_TOOLS>
          Disable specific tools after --enabled-tools filtering. Repeat the flag
      --trust
          Trust the working directory for this invocation only
      --worktree [<WORKTREE>]
          Run inside a git worktree under $VIBE_HOME/worktrees. With NAME, create (or reuse) a worktree and branch named NAME. Without NAME, create a new one named after the prompt (or a random slug). Combines with `-c`/`--resume`: the worktree is prepared first and the resume is then scoped to the worktree directory
      --add-dir <ADD_DIR>
          Additional working directory for file access. Repeat the flag
      --check-upgrade
          Check for a Vibe update now, prompt to install it, and exit
  -h, --help
          Print help

Commands:
  update         Check for a Vibe update now (same as --check-upgrade).
