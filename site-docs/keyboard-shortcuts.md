# Keyboard Shortcuts

Press `?` anywhere for the in-app cheat sheet. Single-key shortcuts are ignored while typing in inputs.

| Key | Action |
| --- | ------ |
| `1` | Orchestrator view |
| `2` | Files & Repo view |
| `3` | Project Settings view |
| `4` or `O` | Observability monitor |
| `5` or `D` | Docs (this section) |
| `R` | Retrospective review |
| `Ctrl/⌘ + K` or `C` | UI customization & preferences |
| `G` | System transparency & architecture guide |
| `S` | System settings |
| `P` | Start / pause the compute engine |
| `N` | Focus the new-task input |
| `Esc` | Close any overlay or modal |

Shortcuts can be disabled entirely from UI preferences if they ever fight with assistive tech or browser bindings.
