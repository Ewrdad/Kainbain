### How It Solves the Original Problem

**Original Issue:** User reported "queue number doesnt seem to every go down" - dashboard shows 2 tasks but chip shows 3, couldn't understand why the number doesn't decrease.

**Solution Provided:**
1. User clicks the queue chip in the bottom bar
2. QueuePopupModal opens showing the dispatch order
3. User can see which tasks are blocked/waiting/paused
4. User can see which tasks are failed/cancelled
5. Footer explains: "3 open tasks counted · 1 shown in the dispatch queue. Failed, cancelled, waiting-human tasks count toward the number but never dispatch."

Now users have visual debugging to understand why the queue number doesn't decrease!
