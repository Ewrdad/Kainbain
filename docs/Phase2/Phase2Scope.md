# Phase 2 Dogfood ready

## Goal
The goal for phase 2 is to get the app in a good enough state it can be used to develop itself further. 

### Frontend
- Must be usable to interact with engine
- Must be able to support basic workflow usage
- Must be able to start/stop compute
- Must be able to submit, edit and monitor tasks
- Must of layed out the basics of a design pattern
- Must be easy extendable
- Must correctly link to docs generated
- Must allow for tracking of how a job has done

### API 
- Must be able to schedule tasks in order
- Must be able to correctly curate prompts from multiple sources for agent runs
- Must be able to handle UI interactions
- Must be able to Handle fail back behaviour
- Must be able to handle both Code and Documentation tasks
- Must be able to handle projects located in many locations
- Must be easily extendable

## Approach 
Where as Phase 1 was a lot rougher, phase 2 we will be working with design documents and strict requirements that need to be provably met
