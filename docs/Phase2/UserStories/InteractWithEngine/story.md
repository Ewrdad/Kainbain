# User Story: Interact with the Engine

**As a** developer,
**I want to** use a functional frontend to communicate with the backend engine,
**so that** I can trigger and manage agent activities without manually calling the API.

## Acceptance Criteria

- [ ] There is a basic communication channel between the frontend and the API.
- [ ] UI actions trigger corresponding API requests.
- [ ] API responses are correctly rendered in the UI.
