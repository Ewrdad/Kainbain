# User Story: Prompt Curation

**As a** developer,
**I want to** curate prompts for agent runs from multiple sources,
**so that** the agent has all the necessary context and constraints.

## Acceptance Criteria

- [ ] The API can aggregate context from system prompts, user inputs, and project-specific files.
- [ ] Prompts are assembled in a consistent and optimized format for the LLM.
- [ ] There is a way to preview the final curated prompt before execution.
