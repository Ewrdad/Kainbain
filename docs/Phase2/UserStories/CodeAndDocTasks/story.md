# User Story: Code and Documentation Tasks

**As a** developer,
**I want to** the agent to handle both code implementation and documentation tasks,
**so that** the codebase remains synchronized with its documentation.

## Acceptance Criteria

- [ ] The system can distinguish between "code" tasks and "doc" tasks.
- [ ] Code tasks can trigger tests and builds.
- [ ] Doc tasks can update markdown files in the project documentation.
- [ ] Cross-referencing between code and docs is maintained.
