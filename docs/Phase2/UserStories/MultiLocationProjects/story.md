# User Story: Multi-Location Projects

**As a** developer,
**I want to** be able to handle projects located in many different locations,
**so that** the agent can work across multiple repositories or local directories.

## Acceptance Criteria

- [ ] The API supports specifying multiple root paths for a project.
- [ ] The agent can resolve files and symbols across different project locations.
- [ ] The UI allows switching between or aggregating views from multiple project locations.
