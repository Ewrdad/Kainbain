# User Story: Job Tracking

**As a** developer,
**I want to** track exactly how a job was completed, including the sequence of agent actions,
**so that** I can audit the process and improve the agent's performance.

## Acceptance Criteria

- [ ] The system records a history of all tool calls and agent decisions for a job.
- [ ] The sequence of events is presented chronologically in the UI.
- [ ] Each step in the process is linked to its output or result.
