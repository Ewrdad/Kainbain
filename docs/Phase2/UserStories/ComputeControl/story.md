# User Story: Compute Control

**As a** developer,
**I want to** be able to start and stop the compute resources via the UI,
**so that** I can manage resource consumption and costs.

## Acceptance Criteria

- [ ] There is a "Start" button to initialize compute/engine resources.
- [ ] There is a "Stop" button to gracefully shut down compute/engine resources.
- [ ] The UI reflects the current state (Running/Stopped) of the compute.
