- **Best practices?** Yes. Fail-closed enqueue (`UNKNOWN_COMMAND`), fail-open reads (junk → `latest`, never stranded), never-downgrade enforced in three layers (UI disable, backend floor, update-client pre-checks), at-most-once delivery (ack-before-exit prevents restart loops), R1 "never a dead button" throughout.

The `api/gitGate.test.js` test-only hardening is out of scope but was required to unblock the gate signal (see below); it touches no product code. The known `$INSTALL_ROOT/bin` shim-refresh gap is documented in the upgrade-safety review and degrades to a systemd restart, not a stranded runner.
- **Docs updated?** Yes. ADR 0012 Amendment 2, `docs/runner-update-runbook.md` (Restart vs Update, per-runner setting, restart-loop + pin triage), spike notes, survey, implementation plan.
