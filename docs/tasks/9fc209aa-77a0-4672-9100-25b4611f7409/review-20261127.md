2. **Runner silent pass (F4/F5).** `runner/harness.js` latches the first `run_error` into an
   additive `sessionError`; `decideAgentStageVerdict` fails agent stages on it (precedence:
   fail_stage > sessionError > text); `runner/daemon.js` reports `failed`/`infrastructure`.
   Empty SUCCESS runs report `AGY_EMPTY_RUN` on exec and ACP paths. Proof: independent probe
   asserts missing-binary → `AGY_BIN_MISSING` + failed, empty fixture → `AGY_EMPTY_RUN` +
   failed with no `run_finished` — 12/12 PASS.
