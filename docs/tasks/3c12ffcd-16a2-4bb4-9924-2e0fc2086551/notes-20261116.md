## Deviations from the plan (all deliberate)

1. The engine's early history entry is mode-neutral ("Fast-gate FAILED:
   \<suites> (verdict: \<path>) — full detail lands in the stage report when
   the command exits") instead of the plan's "canary still running" wording,
   which would be false in fail-fast mode.
2. Assertion-line survival is asserted at the 4000-char retry budget (the
   plan's Phase 4.3 level) plus the full report and full-log files; the
   3072-char timeline row carries suite names + verdict paths (its
   head+tail window cannot also reach the mid-log Details tail — proven,
   not assumed, by the characterization test).
3. Added `docs/tasks/local-gate-runs/` to `.gitignore` (leak guard: local
   verdict full-logs are run history, never branch content).
