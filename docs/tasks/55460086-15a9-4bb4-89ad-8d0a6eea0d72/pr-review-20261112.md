## Verdict summary

**PASS.** The branch makes dispatch and direct claims resolve each task's
stage from the task's own pipeline (`task.workflowId` via
`resolveStagesForTask`) instead of the viewed pipeline's `project.stages`
mirror, which is the verified root cause of "only the active pipeline's tasks
get picked up".
