# Creative Ideas for "Hello World" in Python

## Idea 1: Classic Minimal
```python
print("Hello, World!")
```

## Idea 2: With Variables
```python
greeting = "Hello"
target = "World"
print(f"{greeting}, {target}!")
```

## Idea 3: Using a Function
```python
def hello_world():
    return "Hello, World!"

print(hello_world())
```

## Idea 4: Class-based
```python
class Greeter:
    def __init__(self, name="World"):
        self.name = name
    
    def greet(self):
        return f"Hello, {self.name}!"

print(Greeter().greet())
```

## Idea 5: ASCII Art Style
```python
print("""

  / __ \/ __ \/ ___// __ \/ __ \
 / /_/ / /_/ (__  )/ /_/ / /_/ /
/_____/\____/____/ \____/\____/
""")
print("Hello, World!")
```

## Idea 6: Interactive
```python
name = input("What's your name? ") or "World"
print(f"Hello, {name}!")
```

## Idea 7: Multilingual
```python
import random
greetings = {
    "English": "Hello, World!",
    "Spanish": "¡Hola, Mundo!",
    "French": "Bonjour, Monde!",
    "German": "Hallo, Welt!",
    "Japanese": "こんにちは、世界！",
    "Chinese": "你好，世界！"
}
print(random.choice(list(greetings.values())))
```

## Idea 8: With Time Context
```python
from datetime import datetime
hour = datetime.now().hour
if hour < 12:
    greeting = "Good morning"
elif hour < 17:
    greeting = "Good afternoon"
else:
    greeting = "Good evening"
print(f"{greeting}, World!")
```

## Idea 9: Using sys.stdout (lower level)
```python
import sys
sys.stdout.write("Hello, World!\n")
```

## Idea 10: One-liner with __main__ guard
```python
if __name__ == "__main__": print("Hello, World!")
```
