## Verdict: PASS — suitable to integrate

## Does it achieve the goal? Yes (proven)

Acceptance: a task referencing `assets/image.png` either has a readable file
in the workspace or its prompt carries the missing-asset warning.

- Warning arm, proven end-to-end: `PromptCurationEngine.curatePrompt` on a
  task with goal `See ![image.png](assets/image.png)` and no bytes renders a
  prompt starting with `# Missing Task Assets\n`, containing `MISSING-ASSET`,
  `assets/image.png`, and `docs/tasks/task-dangle/assets/image.png`, with the
  warning positioned before `# Task`. Same goal with the file on disk, and a
  ref-free goal, render with no warning and still start with `# Task`.
- Detection arm, proven: `findMissingAssetRefs` returns the exact
  `{ref, name, expectedPath}` entry for the dangling ref and `[]` once
  `writeTaskImage` lands the bytes; drifted-but-servable
  (`assets/My Shot.PNG` vs on-disk `my-shot.png`) resolves `present: true`.
- Delivery arm, proven: `collectTaskAssetPayload` ships the on-disk image as
  base64; `writeClaimTaskAssets` writes it byte-identical to
  `docs/tasks/t1/assets/` in a fresh worktree. Runner suites pass:
  `runner/project.test.js` 35/35, `runner/daemon.test.js` 145/145 via
  `node --test` (includes the new local-sync, claim-write, and
  single-assignment remote-delivery tests).
- No silent third state: per ref, either the file resolves or the warning
  names it; `resolveAssetRef`/`findMissingAssetRefs`/`writeClaimTaskAssets`
  are total (never throw), and the curation hook is wrapped so dispatch
  without the warning beats failed dispatch.

  `api/work/taskAssets.js` owns resolve/find/format/payload. Unit tests
  beside each.

  and `curateRunnerPrompt` paths share), first-section placement via the new

  first stage; branch-flap second look via `filterBranchBackedRefs`

  doubt).

  extended (copy-or-warn, warning text, self-healing, remote note, grammar
  owner).
- All six plan success criteria hold, including byte-identical prompts for
  healthy tasks (proven: `renderPromptLayout` with the new default layout
  vs the old layout renders byte-identical when the warning is empty) and
