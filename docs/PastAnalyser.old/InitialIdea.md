# Past analyser

We want to analyse how past workflows executed in order to reduce AI usage as much as possible (due to cost/and limits). This is to feed into a feedback loop where we reduce effort, but can be applied to any project.

## Goals
- To make projects more AI efficient over time
- To allow kainbain as a whole more AI efficient with time
- To identify where we can use smaller models to reduce load
- To identify where we are using too small models and need to upgrade.
- To continue to support great flexibility


## Ideas
These are some rough ideas on how we can do that

- AGENTS.md optimizer
  - gemini.md,claude.md etc 
- Agent tool creator
  - skill creator
  - CLI tool
- Refactor needed detector
- DORA metric analyser
  - for cost only not speed 
- workflow analyser
  - First pass analysis
  - Frequent loops
  - AI breakdown/combine analysis 
- Token tracking / cost estimates
- Model performance estimates (Number of fails per model)
