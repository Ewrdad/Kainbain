## Addendum 2026-11-13 — fallback removed

Task `7b5a1bd8-9455-43e5-95d6-698a2dc7f782` removed both embedded fallbacks described above. The backend never spawns an in-process agent (or runs a CI stage) for a runner-servable stage: with `KAINBAIN_RUNNER_EXECUTION_ONLY=1` the defer gate in `executeStage.js` is a hard defer — empty registry, stale fleet, capability miss, and long waits all stay `deferred: "runner-dispatch"`. This matters because the backend container has no provider credentials and no harness CLIs, and mounts only `/home/server/projects` and `/home/server/.kainbain` (not `/home/server/apps`), so every embedded fallback run failed (e.g. "No API key found for mistral", `spawn agy ENOENT`, `cd: cant cd to /home/server/apps/kainbain`). `isRunnerDispatchFallbackDue` and the `KAINBAIN_RUNNER_DISPATCH_FALLBACK_MS` config key are deleted (a legacy value in an env file is silently ignored); only `isRunnerClaimable` survives, as a dispatch utility no longer consumed by the gate. Starvation visibility is unchanged: scheduler stats `deferredDispatch` / `lastOutcome = deferred-runner-dispatch` and the Runner settings screen's "N deferred to Runners". The historical body above is kept as-is.
