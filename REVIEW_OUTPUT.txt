### How It Solves the Original Problem

**Original Issue:** User reported queue number "doesn't seem to ever go down" - dashboard shows 2 tasks but chip shows 3, couldn't understand why the number doesn't decrease.

**Solution:**
- Click the queue chip in the bottom bar → QueuePopupModal opens
- See the dispatch order with position badges
- View task details including blocked/waiting/paused/failed status
- Footer explains: "3 open tasks counted · 1 shown in the dispatch queue. Failed, cancelled, waiting-human tasks count toward the number but never dispatch."

Now users can visually debug why the queue number doesn't decrease!
